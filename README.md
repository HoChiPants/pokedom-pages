# Pokedom support website

Standalone static GitHub Pages site for the Pokedom offline iPhone beta by Studio Minden.

- Support: https://hochipants.github.io/pokedom-pages/
- Privacy: https://hochipants.github.io/pokedom-pages/privacy/
- Terms: https://hochipants.github.io/pokedom-pages/terms/

The public site contains only support and policy documents, inline CSS and relative navigation. It has no scripts, forms, external assets, cookies, analytics or runtime dependencies. GitHub’s separate hosting logs are described in the privacy policy.

Publish the repository root from the main branch using GitHub Pages. This repository is separate from the private iOS app, the online server and the Messages Wrapped website. Those projects and their private source do not belong in this repository.
